The repository's license is [MIT](../LICENSE). Generated [third-party notices](../THIRD_PARTY_LICENSES.txt) accompany the bundled runtime and interfaces. Node's matching license is copied into each Mac app separately.

## Fluid Functionalism

Buttons, checkboxes, scrolling, and supporting code come from [Fluid Functionalism](https://github.com/mickadesign/fluid-functionalism), revision e07409c0f50dea93e68c749021ed672e9dce910a. Its ScrollArea includes an adaptation of [Lina](https://github.com/SameerJS6/lina). Both complete MIT notices are included under `src/vendor/fluid` and in the generated notices. `ORIGIN.json` records file hashes and source URLs.

## Artwork

The abstract amber-glass icon was generated with OpenAI's image-generation tool for this project, selected by the author, and then cleaned at its outer edge with the author's approval. `desktop/AppIcon.png` is the approved source. Native packaging derives the Mac icon sizes from it.

The README workflow video uses synthetic passages and annotations. It is hosted as a GitHub attachment.

The 60-second MP4 renders at 1440 × 960 pixels and 60 frames per second. It follows an agent request, a two-second thinking state, a draft opening in a Markdown editor, annotation through the production web interface with Fluid controls, and feedback sent as an attachment to the same conversation. It ends with a staged agent reply and a revised draft incorporating both comments. Its isolated bridge verifies both saved annotations, the resulting Markdown attachment, the sent message, and both revisions. Cursor movement, typing, transitions, key indicators, and the panel backdrop are rendered for the demonstration. The running Mac app uses Apple’s native frosted material.
